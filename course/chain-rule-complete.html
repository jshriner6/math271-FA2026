    Worksheet Directional Derivative, Total Derivative, and the Chain Rule (Complete)

    1. Motivation.

    🔗
    Solution.
    We’ve seen how we can use the calculus 1 derivative to define partial derivatives for multivariable functions. We’ll see how we can use partial derivatives to establish more tools, all with the purpose of of understanding the rate of change of a multivariable function.
    🔗
    🔗
    🔗

    2. Directional Derivatives.

    For \(f(x,y)\text{,}\) \(f_x\) and \(f_y\) helped us describe the rate of change of \(f\) in the \(x\) and \(y\) directions, respectively. But in the \(x-y\) plane, there are lots more directions!
    🔗
    Solution.
    To specify a direction, we can use a vector of magnitude \(1\text{,}\) called a unit vector.
    🔗
    For a unit vector \(\uvec = \langle a, b\rangle \text{,}\) the rate of change of \(f(x,y)\) in the direction \(\uvec\) at the point \((x_0,y_0)\) is given by
    \begin{align*} D_{\uvec}f(x_0,y_0) \amp= \langle f_x(x_0,y_0), f_y(x_0,y_0) \rangle \cdot \langle a, b\rangle\\ \amp= af_x + bf_y \end{align*}
    🔗
    The vector \(\langle f_x(x_0,y_0), f_y(x_0,y_0) \rangle\) is called the gradient of \(f\) at \((x_0,y_0)\text{,}\) and is commonly denoted as \(\nabla f\text{.}\) This vector points in the direction of steepest ascent of \(f\) at \((x_0,y_0)\text{.}\)
    🔗
    🔗
    🔗

    3. Example: Directional Derivative.

    Consider \(f(x,y) = x^2 - y^2\) near the point \((1,2)\text{.}\)
    🔗
    Solution.
    We can compute \(\nabla f(x,y) = \langle 2x, -2y \rangle\text{,}\) so that \(\nabla f(1,2) = \langle 2,-4 \rangle\text{.}\)
    🔗
    If we’d like to know how \(f\) changes in the direction \(\langle -1, 1 \rangle \text{,}\) we first need the associated unit vector, \(\uvec = \langle \frac{-1}{\sqrt{2}}, \frac{1}{\sqrt{2}}\text{.}\) Then we compute
    \begin{align*} D_{\uvec}f \amp= \nabla f \cdot \uvec \\ \amp= \frac{-2}{\sqrt{2}} - \frac{4}{\sqrt{2}} \end{align*}
    Since this is less than zero, we know the function decreases in the direction \(\uvec\text{.}\)
    🔗
    We could also compute in which direction(s) \(\vvec = \langle v_1, v_2 \rangle\) the function stays constant. This is solving \(D_{\vvec}f = 0\text{,}\) which is equivalent to \(2v_1 - 4v_2 = 0\text{,}\) which means \(v_1 = 2v_2\text{.}\) If we require that \(\vvec\) is a unit vector, then we obtain \(v_1 = \pm \frac{2}{\sqrt{5}}\) and \(v_2 = \pm \frac{1}{\sqrt{5}}\text{.}\)
    🔗
    See the directional derivative Desmos interactive to visualize all of these computations.
    🔗
    🔗
    🔗

    4. Total Differential.

    Partial derivatives let one variable change, and hold all others constant, which is not always desirable in practice (we’d like multiple variables to change at the same time). Directional derivatives are one tool, as they allow us to “walk” in any direction and see how a function changes.
    🔗
    Another tool is the total derivative, which makes use of a surface’s tangent plane:
    🔗
    Suppose \(P(T,V)\) gives the pressure of a gas at temperature \(T\) and volume \(V\text{.}\) How does \(P\) change as both \(T\) and \(V\) change?
    🔗
    Solution.
    Using the equation of a tangent plane, we can write that for a temperature/volume pair \((T,V)\) close to the initial temperature/volume pair \((T_0, V_0)\text{,}\)
    \begin{equation*} P(T,V) \approx P(T_0,V_0) + \frac{\partial P}{\partial T} (T-T_0) + \frac{\partial P}{\partial V} (V-V_0)\text{,} \end{equation*}
    which means
    \begin{equation*} \Delta P \approx \frac{\partial P}{\partial T} \Delta T + \frac{\partial P}{\partial V} \Delta V\text{.} \end{equation*}
    The total differential is the approximate value we get from using the tangent plane on the right hand side, written
    \begin{equation*} dP =\frac{\partial P}{\partial T} dT + \frac{\partial P}{\partial V} dV\text{.} \end{equation*}
    When \(\Delta T\) and \(\Delta V\) are small, the true change in \(P\) is very close to the total differential; that is,
    \begin{equation*} \Delta P \approx dP\text{.} \end{equation*}
    🔗
    🔗
    🔗

    5. Total Derivative.

    It is common that variables in our function change with respect to a single common variable (like time):
    \begin{equation*} P(T,V) = P(T(t), V(t))\text{,} \end{equation*}
    which is a composition of functions.
    🔗
    In this case, \(dP = \frac{\partial P}{\partial T} dT + \frac{\partial P}{\partial V} dV\) becomes
    🔗
    Solution.
    \begin{equation*} \frac{dP}{dt} = \frac{\partial P}{\partial T} \frac{dT}{dt} + \frac{\partial P}{\partial V} \frac{dV}{dt}\text{,} \end{equation*}
    which is called the total derivative. This gives the approximate change in \(P\) for a small change in \(t\) at a fixed temperature and volume.
    🔗
    🔗
    🔗

    6. Example: Total Differential and Total Derivative.

    Let \(P(T,V) = \frac{T}{V}\text{.}\)
    🔗
    Solution.
    The total differential of \(P\) is
    \begin{equation*} dP = \frac{1}{V}dT - \frac{T}{V^2}dV\text{.} \end{equation*}
    If \(V=10\) L and \(T=273\) K, let’s compute the approximate change in pressure if the volume decreases to \(9\) L and temperature increases to \(274\) K. Using the total differential, we compute
    \begin{align*} dP \amp= \frac{1}{10} \cdot 1 - \frac{273}{100} \cdot (-1) \\ \amp= 0.1 + 2.73 \\ \amp= 2.83 \end{align*}
    Note this is an approximation of \(\Delta P\text{,}\) which in this example we can compute exactly as \(\Delta P = \frac{274}{9} - \frac{273}{10} \approx 3.14\text{.}\)
    🔗
    Now suppose \(T(t) = \sin(t)\) and \(V(t) = t^2\text{.}\) Then we can compute the total derivative as
    \begin{align*} \frac{dP}{dt} \amp= \frac{1}{V}\cos(t) - \frac{T}{V^2}(2t) \\ \amp= \frac{\cos(t)}{t^2} - \frac{2t\sin(t)}{t^4} \end{align*}
    We could verify this derivative directly by writing \(P(T,V)\) as a function of the single variable \(t\text{,}\) and using derivative rules from calculus 1.
    🔗
    🔗
    🔗

    7. The Chain Rule.

    The total derivative is an example of the multivariable chain rule. In general, tree diagrams can be very helpful for keeping track of this rule in more complicated variables.
    🔗

    (a)

    \(f(x(t),y(t))\)
    🔗
    Solution.
    See notes from class for a tree diagram. It should give the formula
    \begin{equation*} \frac{df}{dt} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t} \end{equation*}
    🔗
    🔗
    🔗

    (b)

    \(f(x(t),y(t), z(t))\)
    🔗
    Solution.
    See notes from class for a tree diagram. It should give the formula
    \begin{equation*} \frac{df}{dt} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t} + \frac{\partial f}{\partial z} \frac{\partial z}{\partial t} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    \(f(x(s,t),y(s,t))\)
    🔗
    Solution.
    See notes from class for a tree diagram. It should give the formulas
    \begin{equation*} \frac{\partial f}{\partial s} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial s} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial s} \end{equation*}
    and
    \begin{equation*} \frac{\partial f}{\partial t} = \frac{\partial f}{\partial x} \frac{\partial x}{\partial t} + \frac{\partial f}{\partial y} \frac{\partial y}{\partial t} \end{equation*}
