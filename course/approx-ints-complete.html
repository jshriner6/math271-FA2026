    Worksheet Approximating Integrals (Complete)
    

    1. Motivation.

    🔗
    Solution.
    Evaluating definite integrals can get hard fast! In practice, it is useful to have methods for approximating values of integrals. Typically, this takes the form
    \begin{equation*} \int_a^b f(x) \quad dx \approx \sum_{i=1}^n w_i f(x_i)\text{.} \end{equation*}
    How we determine the weights (\(w_i\)) and the nodes (\(x_i\)) used in the approximation is what varies between methods. We’ll look at some common methods used in quantum mechanics.
    🔗
    🔗
    🔗

    2. The Trapezoid Rule.

    🔗
    Solution.
    See the Trapezoid rule Desmos interactive for the visual used to determine the Trapezoid rule for approximation:
    \begin{equation*} \int_a^b f(x) \quad dx \approx \frac{\Delta x}{2}(f(x_1)+ 2 f(x_2) + \dots + 2f(x_{n-1}) + f(x_n))\text{.} \end{equation*}
    🔗
    🔗
    🔗

    3. Example: Trapezoid Rule.

    \(\displaystyle \int_{-1}^1 e^{-x^2} \quad dx\)
    🔗
    Solution.
    Using \(n=4\) makes \(\Delta x = 0.5\text{.}\) Then using the trapezoid rule gives
    \begin{align*} \int_{-1}^1 e^{-x^2} \quad dx \amp\approx \frac{1}{4}(f(-1) + 2f(-0.5) + 2f(0) + 2f(0.5) + f(1) ) \\ \amp\approx 1.463 \text{.} \end{align*}
    Compare this to the true value using technology of approximately \(1.494\text{.}\)
    🔗
    🔗
    🔗

    4. Simpson’s Rule.

    🔗
    Solution.
    See the Simpson’s rule Desmos interactive for the visual used to determine Simpson’s rule for approximation: For \(n\) even,
    \begin{equation*} \int_a^b f(x) \quad dx \approx \frac{\Delta x}{3}(f(x_0)+ \sum_{i \text{ odd}}^{n-1} 4f(x_i) + \sum_{i \text{ even}}^{n-2} 2f(x_i) + f(x_n) )\text{.} \end{equation*}
    🔗
    🔗
    🔗

    5. Example: Simpson’s Rule.

    \(\displaystyle \int_{-1}^1 e^{-x^2} \quad dx\)
    🔗
    Solution.
    Using \(n=4\) makes \(\Delta x = 0.5\text{.}\) Then using the Simpson’s rule gives
    \begin{align*} \int_{-1}^1 e^{-x^2} \quad dx \amp\approx \frac{1}{6}(f(-1) + 4f(-0.5) + 2f(0) + 4f(0.5) + f(1) ) \\ \amp\approx 1.494 \end{align*}
    which is even closer to the true value than when using the Trapezoid rule.
    🔗
    🔗
    🔗

    \(\displaystyle \int_{-\infty}^{\infty} f(x)e^{-x^2} \quad dx \approx \sum_{i=1}^n w_if(x_i)\text{,}\) where
    🔗
    Solution.
    This method is best for improper integrals of a particular form, and actually gives equality when \(f\) is a polynomial of degree \(2n-1\) or less.
    🔗
    In lab we’ll discover a bit more about where the table of weights and nodes comes from, but for now we should understand how to use them.

    7. Examples: Gaussian-Hermite Quadrature.

    (a)

    \(\displaystyle \int_{-\infty}^\infty e^{-x^2} \quad dx\)
    🔗
    Solution.
    \begin{align*} \sum_{i=1}^2 w_i f(x_i) \amp= 0.886f(-0.707) + 0.886f(0.707) \\ \amp=2(.886) \\ \amp=1.772 (\approx \sqrt{\pi}) \end{align*}
    🔗
    🔗
    🔗

    (b)

    \(\displaystyle \int_{-\infty}^\infty ae^{-\frac{(x-b)^2}{2c^2}} \quad dx\)
    🔗
    Solution.
    Use the substitution \(u = \frac{1}{\sqrt{2}c}(x-b)\text{,}\) \(du = \frac{1}{\sqrt{2}c} dx\) to transform the integral to
    \begin{equation*} \int_{-\infty}^\infty \sqrt{2}c ae^{-u^2} \quad du\text{.} \end{equation*}
    Then using the result from the previous example, we can see that
    \begin{align*} \int_{-\infty}^\infty \sqrt{2}c ue^{-u^2} \quad du \amp= \sqrt{2}c a \sqrt{\pi}\\ \amp= ac\sqrt{2\pi} \text{.} \end{align*}
    This result allows us to normalize a general Gaussian function!
